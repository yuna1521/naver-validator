# 입점 상품 최저가 검수

브랜드사가 제출한 "애드웰 상품제안서"(`.xlsx`)를 업로드하면, 각 상품의 기재 최저가가 실제 네이버 쇼핑 최저가와 정합한지 자동으로 검수해 결과를 원본 엑셀에 덧붙여 다운로드한다.

## 검수 항목

- 기재 최저가 vs 네이버 실제 최저가 (허용 오차 기본 ±5%, 1~20% 조정 가능)
- 우리 판매가의 시장 경쟁력 (공급가 / (1 − 수수료율))
- 검색 시장 풍부도 (총 검색 결과 수, 가격 범위)
- 가격 변동성 신호 (1위만 비정상적으로 저렴한 일회성 특가 감지)

## 빠른 시작

```powershell
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열리면 상품제안서 `.xlsx`를 끌어다 놓고 **검수 시작** 클릭.

## 네이버 API 키 설정

네이버 개발자센터에서 "검색" API 신청 후 키 발급. 두 가지 방법 중 하나:

**1. 로컬 (.env)**
```
NAVER_CLIENT_ID=발급받은_ID
NAVER_CLIENT_SECRET=발급받은_SECRET
```

**2. Streamlit Cloud 배포 시 (`.streamlit/secrets.toml`)**
```toml
NAVER_CLIENT_ID = "발급받은_ID"
NAVER_CLIENT_SECRET = "발급받은_SECRET"
```

두 파일 모두 `.gitignore`에 포함되어 있다. 키 없이 실행하면 검수 메모에 "API 키 누락"이 표시된다.

## 입력 양식

**애드웰 상품제안서 양식 전용**이다. 양식 가정:

- 첫 시트, 1행 제목, **2행 헤더, 3행부터 데이터**
- 원본 컬럼 16개(A~P). 검수 결과는 Q열부터 5개 컬럼이 추가된다.
- 컬럼명은 `core.py`의 `COL_MAP`에 정의 (예: `정가\n(A)`, `공급가\n(B)`)

양식이 바뀌면 `COL_MAP`과 `excel_writer.py`의 `ORIG_COL_COUNT` 동시 수정 필요.

## 결과 해석

각 상품은 다음 둘 중 하나로 판정된다:

- **승인 가능** — 매칭 OK, 판매가 ≤ 네이버 최저가, 기재가 정합, 이상치 없음 (모든 조건 충족)
- **확인 필요** — 위 중 하나라도 실패. 사유는 "검수 메모"에 ` / `로 연결되어 표시

다운로드된 엑셀은 원본의 서식·수식·셀 병합을 그대로 보존하며, Q~U열에 결과 / 네이버 조회가 / 차이 / 시장 풍부도 / 검수 메모가 추가된다.

## 사용 팁

- 처음에는 사이드바의 **테스트 모드**(처음 N건만)로 동작 확인 후 전체 실행 권장.
- API 한도(일일 호출 수) 도달 시 자동 중단되고, 그 시점까지의 결과만 표시·다운로드된다.
- 같은 브랜드의 다른 모델(예: AQ-101 vs AQ-120)이 잘못 매칭되지 않도록 모델 코드 기반 매칭이 우선 적용된다. 모델 코드가 없는 상품은 단위(75ml, 2kg 등) + 키워드로 매칭한다.

## 구성

- `app.py` — Streamlit UI
- `core.py` — 검수 로직, 네이버 검색, 매칭/필터링
- `excel_writer.py` — 원본 보존 + 결과 컬럼 추가
- `requirements.txt` — 의존성 (streamlit, pandas, openpyxl, requests, python-dotenv)

내부 구조와 매칭 알고리즘 상세는 `CLAUDE.md` 참고.
